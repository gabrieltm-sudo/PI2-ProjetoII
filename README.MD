# Projeto Integrador II - Projeto II

Simulador de uma arquitetura MiniMIPS de 8 bits utilizando uma organização multiciclo, implementado em C, com execução interativa por menu e suporte a operações de carga/armazenamento, instruções aritméticas/lógicas e controle de fluxo.
